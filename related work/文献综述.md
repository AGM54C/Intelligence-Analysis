# 相关工作：任务、机制与比较边界

本综述围绕不可靠图文证据下的动态事件推理组织代表工作，区分已有能力与需要检验的问题。它不构成穷尽性检索或方法新颖性的证明。逐篇内容见[论文目录](README.md)，五篇核心工作的实验细节见[方法与实验比较](方法与实验比较.md)。

| 方向 | 代表工作与核心思路 | 对研究问题的约束 |
|---|---|---|
| 图文取证 | [AVerImaTeC](https://arxiv.org/abs/2505.17978) 将核验拆为有网页出处的问答证据，动态提问利用已有证据历史 | 图片、检索、多轮取证均有直接先例；证据修订后的候选状态需单独检验 |
| 模态偏差 | [VERITE](https://arxiv.org/abs/2304.14133) 用模态平衡减少单模态捷径 | 必须有去图及合法视觉关系变体；不能把改造任务的成绩称为原基准成绩 |
| 图文错配与解释 | [NewsCLIPpings](https://arxiv.org/abs/2104.05893)、[MOCHEG](https://doi.org/10.1145/3539618.3591879) 分别研究受控错配与多模态检索、核验和解释 | 静态错配不自动给出自然修订历史；图片及标签不能泄入答案 |
| 冲突材料 | [CONFACT](https://doi.org/10.24963/ijcai.2025/1073) 比较在检索、排序、生成中引入来源背景 | 来源可信度不等于内容真实性与相关性，复杂来源策略并非总能提高效果 |
| 来源依赖 | [Dong et al.](https://vldb.org/pvldb/vol2/vldb09-pvldb47.pdf) 联合考虑复制依赖、来源准确度与数据真值 | 多次转载不能重复计作独立证据；未知来源关系已有研究基础 |
| 假设搜索 | [HypoGeniC](https://aclanthology.org/2024.nlp4science-1.10/) 用有标签样本生成与更新假设；[EvoDiverse](https://arxiv.org/abs/2606.10587) 用多温度种群维持多样性 | 在线事件材料没有免费真值奖励，生成、淘汰和选择错误应分别分析 |
| 假设维护 | [ATMS](https://doi.org/10.1016/0004-3702(86)90080-9) 提供经典假设维护参照 | 保存依赖与撤回依据本身不足以构成新方法；需要明确适配后的基线 |
| 证据图与传播图 | [GEAR](https://aclanthology.org/P19-1085/)、[Bi-GCN](https://doi.org/10.1609/aaai.v34i01.5393) 分别聚合证据语义与传播结构 | 转发边与支持边不同；应比较相同信息条件下的图核查 |
| 多模态与动态图 | [KMGCN](https://doi.org/10.1145/3372278.3390713)、[FGDGNN](https://aclanthology.org/2025.findings-acl.296/) 利用多模态知识图与时间快照 | 多模态和动态图已有先例；增长的传播图与旧依据失效需要区分 |

## 数据与评价的边界

[公开资源目录](../datasets/README.md)列出 25 项数据与获取条件。图文、财务问答、调查图和警务开放记录各自覆盖部分能力，不能直接拼接成具有可靠终局答案的真实情报任务。

[AVerImaTeC 2026 共享任务](https://aclanthology.org/2026.fever-1.6/)使用标注问答辅助查询，并纳入标注证据，适合有条件的检索评测。其知识库不等同于完全未知事件的开放搜索环境。文本取证和反向图像搜索的时间过滤表述需要结合实际字段与实现解释，不能仅凭网页日期宣称无时间泄漏。

旧数据上的受控重排与真实新事件回放应分别报告。正式案例要求事件严格晚于所选模型有依据的知识截止日期，并审计后训练及检索污染；模型发布日期、网页发布日期和合成图生成日期均不能替代这一要求。

## 机制检验

待检验的问题是：当旧证据失效、来源分组改变或竞争候选失去支持时，保存选择依据能否帮助恢复有价值的解释。需要与全量重启、普通候选池、来源去重加同容量档案、经典依赖维护以及图核查比较，固定可见信息和计算条件。

多样性、来源处理和档案的组合可以提供实用系统，但算法贡献还需要超出合理组合基线的机制证据。相关文献笔记按所依据的正文、摘要或元数据限定描述，不将未核对的算法性质写成已确认事实。
