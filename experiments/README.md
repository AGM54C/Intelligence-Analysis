# 实验协议与图文样例

受控实验研究：两条历史最终具有相同有效证据时，继承的候选状态是否影响判断。协议明确区分视觉识别、证据充分性、候选丢失和选择错误。

- [图文证据修订实验](01-图文证据修订先导/README.md)：方法、对照、评价与适用范围。
- [合成样例](data/README.md)：四个场景及输入契约。
- [运行代码](../evidence-pilot/README.md)：安装、测试、dry-run 和 Transformers 推理。

`results/` 为运行时输出路径，由程序创建并从 Git 排除。仓库不包含模型性能结果；合成数据上的程序验证不能证明研究方法有效。
