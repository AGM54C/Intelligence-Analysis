为同一问题构造两条早期信息历史，最终提供相同的有效图文证据。比较单解释更新、全量重启和普通多假设维护，观察旧状态对结论的影响。

- [实验协议](experiment-protocol.md)：假设、方法、公平对照和评价。
- [数据契约](../data/image-text-pilot/data-contract.md)：公共材料、阶段编排、私有标签及图像版本。
- [提示与状态](../data/image-text-pilot/prompts.md)：输入字段、候选身份和输出限制。
- [代码使用说明](../../evidence-pilot/README.md)：可运行命令与运行边界。
