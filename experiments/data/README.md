# 合成图文样例

[image-text-pilot](image-text-pilot/) 包含四个可重复生成的场景：D001 为图像语境，D002、D004 为裁剪上下文，D003 为来源依赖。每例具有实际 PNG、固定问题、分阶段证据、两条信息历史、构造标签与视觉关系变体。

这些样例属于程序测试与受控诊断素材。图像由同一生成器绘制，日期为场景内虚构时间，标签未经独立标注者复核；不能将它们作为知识截止日期之后的真实事件或独立真实世界样本。
