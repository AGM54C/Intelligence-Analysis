# SEC EDGAR

| 项目 | 说明 |
|---|---|
| 类型 | 美国上市公司披露文件与结构化财务数据服务 |
| 模态与标签 | 申报文档、财务表、XBRL；无现成情报问答或逐条真假标签 |
| 获取状态 | 官方入口存在访问限制；下载可用性未验证 |

## 官方获取入口

- [SEC EDGAR API 说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。
- [EDGAR 检索入口](https://www.sec.gov/edgar/search/)。批量获取、请求标识和访问速率应按 SEC 官方规则配置。

## 可用于什么

后续可以围绕公司披露、财务重述、更正申报及同一指标的口径变化，构建公司/行业情报案例。任务可限定为“截至某日，哪些公开材料支持某一经营指标判断”，将当期申报与之后的更正清楚分开。

披露文件也不是无误的全知答案，应记录申报版本、报告期和公开时间。必须区分经营情况真实变化、会计口径变化与历史报告更正。图片/图表需要从实际文档核实，XBRL 数字本身不满足图文要求。若检索直接返回重述后的终局结论，会破坏早期阶段评测。

## 使用条件与限制

官方说明页存在访问限制（2026-10-09 请求返回 HTTP 403），因此仅作为官方资源入口，不保证下载可用性。请求标识、速率、文档素材使用及再分发遵循 SEC 官方规则；披露记录不是预设真假标签的题包。
