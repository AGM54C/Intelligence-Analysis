# UK Police Open Data

| 项目 | 说明 |
|---|---|
| 类型 | 英格兰、威尔士、北爱尔兰警务事件与处理结果开放数据 |
| 模态与标签 | 月度犯罪/反社会行为记录、匿名位置及部分后续处理结果 |
| 获取状态 | 官方 CSV 定制下载、月度归档与 API 可访问 |

## 下载与来源

- [定制 CSV 下载](https://data.police.uk/data/)、[月度归档](https://data.police.uk/data/archive/)。
- [最新完整归档](https://data.police.uk/data/archive/latest.zip)、[JSON API 文档](https://data.police.uk/docs/)。
- [来源、匿名化、质量和许可说明](https://data.police.uk/about/)。

## 可用于什么

相比只有事件统计的表，它还提供部分后续处理结果，可研究公开记录随月份更新的情况。若要重放，应保存每月原始快照，检查事件与 outcome 的关联、遗漏和变动。

结果更新不等于逐条证据被证实或推翻。位置经过匿名化，时间多为月级，不可当作精确案发地点和时刻。公开表没有原始调查证据、照片或完整案卷，也不能据此恢复个人身份或判断个人犯罪责任。

## 使用条件与限制

官网声明 Open Government Licence v3.0，并说明质量限制及事件和法庭结果的匹配过程。匿名位置和月度记录不提供原始图文证据，分析需保留这些限制。
