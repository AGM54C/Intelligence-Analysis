# NYPD Complaint Data Historic

| 项目 | 说明 |
|---|---|
| 类型 | 纽约警方历史报案/投诉记录 |
| 模态与标签 | 报告时间、事件时间区间、罪名描述、行政区等结构化字段 |
| 获取状态 | 官方数据集元数据可访问；支持门户导出与 SODA API |

## 下载与来源

- [纽约官方数据门户](https://data.cityofnewyork.us/Public-Safety/NYPD-Complaint-Data-Historic/qgea-i56i)。
- [元数据](https://data.cityofnewyork.us/api/views/qgea-i56i.json)、[SODA JSON 接口](https://data.cityofnewyork.us/resource/qgea-i56i.json)。

## 可用于什么

适合公共安全趋势、报告与发生时间差异、类型/区域统计的背景分析，可与其他公开材料形成线索筛选流程。

报案、记录分类与最终裁判是不同概念，不能将表中事件直接当作已证实的罪行或对人的指控。数据没有完整案卷和图像，无法直接回答线索真伪、嫌疑解释与逐轮推理问题。与其他城市数据比较时需先统一登记制度与字段定义。

## 使用条件与限制

门户描述含有陈旧的截止年份表述，实际日期覆盖应通过字段查询确认，不据描述推定覆盖到特定年份。使用遵循 NYC Open Data 条款；报案与投诉记录不能直接视为已证实犯罪。
