# CAIL2018

| 项目 | 说明 |
|---|---|
| 类型 | 中文刑事裁判文书与司法预测数据 |
| 模态与标签 | 案情文本；罪名、法条、刑期等裁判相关标签 |
| 获取状态 | 作者 README 提供直接压缩包链接 |

## 下载与来源

- [官方仓库](https://github.com/thunlp/CAIL)。
- [CAIL2018_ALL_DATA.zip](https://cail.oss-cn-qingdao.aliyuncs.com/CAIL2018_ALL_DATA.zip)。小规模/大规模划分及文件结构按作者说明使用。

## 可用于什么

可研究中文案件事实抽取、事件/人物关系整理与法律文本推理，作为警务犯罪方向的文本辅助资源。字段 `fact` 与 `meta.accusation`、法条、刑期等需明确区分。

裁判文书包含事后整理的事实与结果，不是侦查当时可见的原始线索包，不能据此恢复真实调查过程。裁判结果既可能出现在标签字段，也可能残留在叙述中，阶段任务需审查全文泄漏。原数据不含可用图片证据，不能满足图文主任务。

## 使用条件与限制

作者仓库提供数据包入口。开放获取不等于无限再分发原始司法文本，使用需结合项目声明与原始文书条件；裁判文本不等于原始调查过程。
