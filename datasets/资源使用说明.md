# 资源使用说明

本目录提供 25 项公开数据集与开放资源的官方入口、模态、标签、用途及使用条件，不包含第三方原始数据包。链接与获取条件的信息日期为 2026-10-09，实际文件版本和访问规则以提供方为准。

## 获取状态

| 类型 | 含义与限制 |
|---|---|
| 官方文件目录 | 文件名及路径可查；不表示每条样本、图片和标注均已验证 |
| 直接文件或网盘 | 提供方给出下载入口；大文件完整性与原图覆盖率需单独检查 |
| 表单或机构验证 | 使用者需按官方要求申请；公开说明不等于已取得权限 |
| API 或门户元数据 | 可查询数据服务与字段；不保证历史版本完整或记录经过事实裁决 |
| 访问受限或未验证 | 入口已列出，下载可用性不作保证；单次访问失败不代表所有用户无法使用 |

代码许可、论文许可、数据许可和图片原始权利分别处理。条目没有明确许可时，不推定其属于公有领域，也不将作者网盘或公开网页等同于统一再分发授权。

## 任务适用性

弱监督类别、灾害类别、商品评分、报案记录和关系连接各自具有特定含义，不能直接改称事实真假标签。解析表格和关系三元组也不等于视觉输入。已有静态数据可以支持组件对照，但自然补证历史、证据版本、事件时间和阶段充分性需要另有依据。

自建数据的准入条件见[数据集设计约束](../docs/自建数据集设计约束.md)，领域接口见[多领域设计](../docs/多领域数据集设计.md)。

## 更新 CSV 目录

资源卡位于 `01-*` 至 `04-*` 分类目录，更新后在仓库根目录执行：

```bash
python -X utf8 datasets/tools/export_catalog.py
```

该命令生成 [CSV 清单](数据集清单.csv)，不下载原始数据。
