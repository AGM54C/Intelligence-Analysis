# 附录中的典型案例与失败案例分析

本文件是写作与记录规范，尚无正式模型实验案例。正式题包须先满足[自建数据集设计约束](自建数据集设计约束.md)。示例故事、dry-run 输出和随机权重接口结果不能填写为模型成功或失败。

## 案例如何选

主实验确定前定义难例类型，测试结束后按类型、模型结果和基线对照分层选择展示案例。公布每个类型的总数、成功/失败数及选择规则；附录故事用于解释机制，不替代全量统计。

展示范围包括：有效补证后的正确恢复、面对伪更正时正确保持判断、初始池缺失而生成新解释、证据仍不足，以及本方法错误而简单方法正确的案例。没有出现某类结果就如实留空，不能编造或只保留有利案例。自然案例与受控案例分开标记，不能把干预后的材料顺序冒充真实历史。

## 每例共同呈现的材料

| 内容 | 应展示什么 |
|---|---|
| 基本信息 | 事件 ID、领域、固定问题/目标时刻、模型版本和知识截止来源、事件发生时间及证明 |
| 材料与真值 | 原始图文、图像区域、来源/存档、最终核查标签和依据；区分评估者事后知道的内容与当时模型可见内容 |
| 时间线 | 每轮首次出现的材料、修订/转载关系、累计和新增假信息比例、当前可判定范围 |
| 假设变化 | 各方法生成/保留/淘汰/恢复的解释及证据引用，保留候选内容而不只展示内部 ID |
| 评分变化 | 支持、冲突、来源合并及未验证前提的贡献；是哪条材料改变了排序，哪些部分没有改变 |
| 公平比较 | 相同阶段、相同可见证据、模型/搜索权限、候选与档案容量、累计计算成本 |
| 实际结果 | 答案、证据支持、置信度或拒答、格式故障；恢复延迟从证据已充分的阶段开始计算 |

图片和文字引用须可回查，展示中不插入可泄漏答案的人工标题。无需展示模型隐藏思考过程；可用结构化候选、公开输出、引用和分项评分解释更新。

## 失败定位

| 失败类型 | 可观察现象 | 用于定位的辅助对照 |
|---|---|---|
| 视觉识别或图文归属错误 | 看漏区域、读错单位、把相似图片认成同源 | 人工视觉事实或正确对应关系输入，单列 oracle 诊断 |
| 来源/建图错误 | 重复材料当作独立支持，人物或事件误合并 | 同样推理器使用经审查的来源图，单列 oracle 诊断 |
| 评分失真 | 已有正确候选却被无依据的高分故事压过 | 固定候选池比较分项评分与独立标注；检查生成器与评分器共用偏见 |
| 搜索未覆盖 | 合理解释从未被提出 | 固定包含合理解释的候选池仅用于定位覆盖上限 |
| 过早淘汰或恢复失败 | 曾有合理解释，撤回相关依据后仍不能恢复 | 同容量随机/相似度档案检索、经典依赖维护、全量重启 |
| 错误复活或过度翻转 | 新谣言、伪更正让已被充分否定的候选返回 | 保留旧反证的完整有效集合，检查是否只看了被撤回的单条依据 |
| 过度确定或过度拒答 | 证据不足时下结论，或材料充分仍不回答 | 按阶段人工充分性标签分析风险与回答覆盖率 |
| 时间/输入/系统故障 | 使用未来信息、读取私有标签、截断、格式失败 | 可见材料日志、输入哈希与原始输出审计 |

一个案例可能有多个失败原因，允许多标签。只有实际做过控制条件，才能报告该干预下发生了什么；仅凭阅读输出只能写“可能原因”。oracle 对照只用于分解错误，不能并入主方法成绩。

```text
     | 分项评分和引用改变 | 候选生成/淘汰/恢复 | 累计成本

假信息比例：累计曝光 / 当轮新增 / 当前有效 / 去重与来源口径

```

多个种子或模型表现不一致时同时说明，不只取最好的一次。原始运行记录和诊断干预需可追溯，正文主结果仍以独立事件分组统计为准。
