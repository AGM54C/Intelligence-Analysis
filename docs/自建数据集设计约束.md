# 自建图文情报数据集的设计约束

本文件规定公共事件/开源情报、市场/行业调研、警务犯罪/案件调查等自建正式数据集的共同准入条件。网上已有资源继续在 [datasets](../datasets/README.md) 中整理；旧资源可用于阅读、工具开发与辅助对照，不能因重新整理或改写就视为符合新事件要求。

## 1. 目标事件必须发生在所选模型知识截止日期之后

对模型版本 m 记录知识截止日期 c_m，对案例 i 记录目标事件发生时间 t_i。自建正式案例的时间准入条件为：

\[
t_i > c_m.
\]

多个模型共用一份测试集时，事件必须晚于这些模型已核实截止日期的最大值。若使用各模型分别满足条件的子集，要同时报告共同子集，避免因案例不同而直接比较分数。

登记内容包括模型 ID、权重 revision/hash、官方截止日期、说明来源及快照、日期精度、后训练/适配器版本、事件发生区间和证明材料。日期只能精确到月份或区间时，要求事件区间最早端严格晚于截止区间最晚端；重叠或未知不能判定通过。后训练和额外记忆库也需审计，不能只记录底座预训练截止日期。

**不能用新闻发布日期、收集日期或题目改写日期替代事件发生时间。** 旧事件的新报道不符合条件。旧图可以作为新事件调查的背景证据，但被评测的目标事件本身必须发生在时间边界之后；如果问题实际只是询问旧图中的旧事件，它仍属于旧事件题。

模型知识截止日期必须有可核实的来源，不能由模型名称、版本号或发布日期猜测。截止日期未核实的模型—案例组合暂不进入正式主集。固定权重发布时间可以提供额外的保守时间证据，但应单独记录，不能写成厂商公布的知识截止日期。即使时间条件通过，也要排查联网搜索、缓存和更新组件引入的事后答案，不能据此宣称绝对无污染。

## 2. 每个正式案例含真、假材料，比例在案例间不同

主集每个案例在完整调查窗口内须有已核实的真实命题和错误命题。早期某一阶段可以只有一类，也可以主要是暂未核实材料。全真、全假、始终证据不足的案例可作为单独报告的对照，不能替代真假混合主集。

标注基本单位是**有时间、对象、范围限定的原子命题或图文对应关系**。同一文档可以部分真实、部分错误；图片本身真实与“图片属于目标事件”也要分开。来源身份可信不等于它的全部内容真实。

用事后独立核查得到的标签统计某案例在阶段 t 的材料构成：

\[
r^{\mathrm{cum}}_{i,t}=\frac{N^{F}_{i,\le t}}{N^{T}_{i,\le t}+N^{F}_{i,\le t}},\qquad
r^{\mathrm{new}}_{i,t}=\frac{N^{F}_{i,t}}{N^{T}_{i,t}+N^{F}_{i,t}}.
\]

分别报告累计曝光和当轮新增材料中的假信息占比。未知/争议/无法判定的命题另计 N^U，不强行转成假；分母为零时比例缺失。后续撤回的记录仍计入“曾经曝光”的累计统计，同时另报当前有效材料比例，保留它曾影响系统的历史。

至少覆盖低、中、高假信息占比以及不同的时间轨迹。分层边界在构建协议中事先确定；20%、50%、80% 可作为受控压力测试的示例目标，不是已取得的自然数据比例。自然主集依实际材料分层抽样，不能为凑配比伪造自然消息或改写真值。新增受控错误必须单独标明来源、变换和集合性质。

还需分开统计原始曝光次数、去重命题数和独立观察根源：十篇转载可能只有一个错误来源。以哪一种口径计算比例必须公开，不能靠重复同一句话制造案例难度。真实比例、完整来源真值及尚未到来的核查结果都属于评估信息，**不得输入在线适应度、置信度估计或触发策略**。

## 3. 证据按真实时间逐步出现

每个案例保留事件时间、材料发布时间、首次可获取时间、存档时间、实际进入模型的时间及版本。阶段边界由真实发布/核查节点确定，长度和新增材料数可以不均匀，不要求每例都恰好三轮。

后续至少出现能增加区分信息或改变现有证据解释的材料；不能在第一轮暴露全部决定性信息，后面只追加装饰内容。初始歧义及各阶段证据充分性由人工核查，不能根据待测方法是否答错反向选择边界。信息总量随调查增加，但有效证据集合允许撤回、降权或被新版本替代。

需要覆盖多种轨迹：早期误导后出现有效反证；真材料先到而谣言后到；同源转述大量出现但关键独立观测迟到；真实补证与错误“更正”交错；新材料仍不足以区分解释。不能默认“时间越晚越真实”或“每次新增都应翻转结论”。

对自然主集不人为倒置发布时间。静态旧数据重排、受控错配或合成场景用于独立诊断集，不能与自然新事件混合报告，也不能用合成数据的生成日期代替事件发生日期。原有 D001–D004 仅为程序开发材料，不满足这里的自然事件准入要求。

## 4. 区分事后真值与当时能知道什么

私有标注同时保存最终事实、每条材料的最终核查状态、每阶段可接受结论/解释、支撑或反驳依据、仍未排除的替代解释。目标问题和目标时刻固定，避免把真实经营变化、现场变化或案件新进展误当成旧材料错误。

早期缺证时，合理保留多个解释或回答证据不足应获得正确评价，不能要求模型提前知道结局。最终仍不能确定的案例单列不充分证据子集，并保留争议来源，不能为了获得唯一答案删除不利证据。

识别真假是模型任务。主设置不给每条新材料附上 gold 真假、完整来源图或“该反证已足够”的信号。公开更正通知可以成为当时可见证据，系统仍需判断其真实性与适用范围。人工提供撤回状态、正确图或视觉事实的实验均单列辅助诊断。

## 5. 图文证据与时间受限搜索

每个主集案例都有可取得的图片字节和对应文字，并记录图片出处、版本、哈希与必要区域；需要视觉才能核实至少一条与目标有关的约束。关系三元组不等于图片模态；文字已经泄露全部图像事实的题目不承担视觉推理结论。

检索只能返回当前时刻已存在且准入的材料版本。未来网页正文、缓存、搜索摘要、图像反搜结果、URL/文件名中的终局标签均需审计。允许查原始材料和出处，不允许借检索直接读取用于评分的终局答案包。若某一时刻的真实报道直接陈述答案，应按预先制定的规则处理：真实回放轨可保留并检验佐证，多跳子集对肯定/否定裁决作对称过滤，二者分开报告。

## 6. 必须覆盖有机制解释的 hard cases

| 难例类型 | 困难来自哪里 | 需要的判定依据与对照 |
|---|---|---|
| 虚假多数、真实少数 | 同源错误被多次转载，真实材料数量少 | 曝光比例与独立观察分开；增加副本不应凭空增加独立支持 |
| 关键反证迟到 | 早期合理解释被错误材料压低，后续反证足以修订 | 标出最早证据充分阶段；比较重启、普通候选池和恢复 |
| 错误更正迟到 | 最晚的“澄清”本身失实或与目标无关 | 有效反证与伪更正匹配对照，检验过度翻转 |
| 真图配错语境 | 图片真实但日期、地点、对象或图注不符 | 原图和对应关系可回查；去图后应损失有效信息 |
| 裁剪/单位/口径混淆 | 关键区域不可见，或图表轴、期间、统计口径不同 | 完整图/原页面及明确目标时刻；不可把状态变化混为真伪变化 |
| 独立性后来被推翻 | 多条支持后来发现共用原始观测，或关系图存在抽取错误 | 保留关系版本；检测排序变化是否来自证据修订而非新结论泄漏 |
| 初始解释遗漏答案 | 正确解释从未进入初始候选集 | 区分生成新候选与恢复旧候选，不能只靠预装正确解释过关 |
| 长期证据不足/部分未知 | 多个解释始终与当前材料相容 | 接受有依据的不确定性，同时测量无谓拒答 |

hard 的纳入标准是上述结构和人工判定依据，不是“我们的方法赢了”或“某一个基线失败”。保持常规样本与难例的完整结果，报告类别频次和交叉分布，不只挑选戏剧性反转。不同来源、事件、原图、报告/案情组隔离；阶段、改写和图片变体不作为独立事件扩充统计样本数。

## 7. 附录与验收

正式研究需包含[典型案例与失败案例分析](案例与失败分析规范.md)，展示真实材料、时间线、候选变化、依据变化和失败位置。至少覆盖成功恢复、正确保持原结论、需生成新解释、证据不足，以及方法输给简单基线的真实失败；只有实际出现的结果才能填入对应位置。

案例入库时逐项登记：时间边界、真假混合、比例口径、材料逐步公开、图片可用与视觉必要性、各阶段可判定性、来源/版本、泄漏审查、事件分组及标注分歧。缺项标为待补或排除，保留原因；满足约束是准入条件，不等于已经构建完成或方法有效。
